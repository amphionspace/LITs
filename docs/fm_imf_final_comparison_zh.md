# FM 与 IMF 综合评测对照

本报告保留 **150k checkpoint** 的对比口径。IMF 后续已完成 170k / 500 epoch；实际训练、数据、LR 和最终结果见 [IMF 训练完成记录](imf_training_record_zh.md)。

主表均按 **FM 150k / IMF 150k** 排列。FM 使用 10 步推理，IMF 使用 2 步；固定评测文本、样本种子规则、参考录音及 Vocos 一致。错误率越低越好，相似度和音质评分越高越好。

**结论：IMF 在这套固定评测上的目标文本 ASR 错误率较低，但自动音质评分仍低于 FM；duration 相关性略有提高，时长变化压缩的问题仍在。** 中文评测文本含重复和口吃式片段，低 CER 不能直接解释为实际朗读更自然、更稳定，见第 6 节。

## 1. 识别准确率与音色相似度

使用同一套 650 条生成评测样本。CER/WER 为 micro 错误率；中文 WER 不适用。每格均为 **FM / IMF**。

| 分组 | 句数 | CER% ↓ | WER% ↓ | WavLM+ECAPA ↑ | CAMPPlus ↑ |
| --- | --- | --- | --- | --- | --- |
| 目标中文 | 200 | 0.503 / 0.291 | — / — | 0.7855 / 0.7802 | 0.6970 / 0.7091 |
| 目标英文 | 200 | 0.346 / 0.293 | 0.869 / 0.773 | 0.7584 / 0.7495 | 0.8102 / 0.7834 |
| 目标混读 | 50 | 1.862 / 0.000 | 10.417 / 4.167 | 0.7274 / 0.7254 | 0.6753 / 0.6846 |
| LJS 英文 | 200 | 0.346 / 0.388 | 0.917 / 1.255 | 0.6690 / 0.6473 | 0.8346 / 0.8395 |

目标 450 句的平均 WavLM+ECAPA 为 **0.7670 / 0.7605**，CAMPPlus 为 **0.7449 / 0.7394**。两种相似度模型并不总是给出同方向的变化：IMF 的 WavLM 四组都低，而 CAMPPlus 在中文、混读、LJS 略高。

混读 CER 包括归一化后的中英文字符；WER 只统计英文/数字词。IMF 混读 CER=0，但 WER=4.167%，对应 `QR code` / `Q R code`、`Wi-Fi reminder` / `WiFi reminder` 等词切分差异，不能理解为所有发音和词边界完全无误。

## 2. 音质各分项

DNSMOS 是自动预测评分，不是人工 MOS。OVRL 为整体音质，SIG 为语音质量，BAK 为背景质量；P.808 是另一评分输出。目标合计不含 LJS。每格均为 **FM / IMF**。

| 目标混读 | 3.3834 / 3.3411 | 3.6257 / 3.5991 | 4.1510 / 4.1171 | 3.9490 / 3.9672 |

## 3. Duration 相关性：与之前相同的 raw 口径

使用固定 **632 条验证录音**，不是上面的 650 条生成评测。只统计语音 token，排除静音、标点和独立声调，目标英文与 LJS 英文分开。

- **raw**：`exp(logw)`，尚未取整或推理限幅。
- **Corr**：预测时长与当前模型自身 MAS 时长的 Pearson 相关性。
- **Std / CV / 均值比**：预测值与 MAS 的对应统计之比，接近 1 仅表示接近 MAS。
- **MAE**：平均绝对误差，单位为帧，1 帧=16ms。

**两模型的 MAS 路径会变化，MAS 也不是人工真值，因此这些结果衡量与自身对齐的一致性，不能直接当作真实时长准确率排名。** 每格均为 **FM / IMF**。

| 分组 | 句数 | Corr ↑ | Std 比 | CV 比 | 均值比 | MAE（帧）↓ |
| --- | --- | --- | --- | --- | --- | --- |
| 目标中文 | 192 | 0.6557 / 0.6792 | 0.6625 / 0.6721 | 0.7107 / 0.7170 | 0.9322 / 0.9374 | 1.1136 / 1.1015 |
| 目标英文 | 115 | 0.6422 / 0.6527 | 0.6588 / 0.6577 | 0.7358 / 0.7348 | 0.8953 / 0.8951 | 1.2841 / 1.3218 |
| 目标混读 | 93 | 0.6633 / 0.6856 | 0.6819 / 0.6854 | 0.7381 / 0.7389 | 0.9238 / 0.9275 | 1.1981 / 1.1887 |
| LJS 英文 | 232 | 0.6438 / 0.6462 | 0.6667 / 0.6543 | 0.7074 / 0.7059 | 0.9426 / 0.9269 | 1.2888 / 1.3913 |
| 全部合计 | 632 | 0.6509 / 0.6633 | 0.6686 / 0.6667 | 0.7201 / 0.7210 | 0.9284 / 0.9247 | 1.2229 / 1.2633 |

中文 Corr 从 **0.6557 → 0.6792**，Std 比从 **0.6625 → 0.6721**，有小幅改善。目标英文 Corr 虽提高，但 Std 比几乎不变、MAE 更高；LJS 的 Std 比和 MAE 也变差。因此不能说 duration 全面改善。

各组 Std 比仍约为 **0.65–0.69**，说明预测时长的长短变化比各自 MAS 平缓。中文逐句消除整体语速差异后的 Std 比仍为 **0.7134 / 0.7261**，这种压缩不能只用整体语速解释。

## 6. 155k 中文音频的重复反馈核查

针对 `step_00155000/wavs/majestic_zh` 的 200 个文件，核对了输入文本、音素、既有逐句 ASR、同一步 FM 结果和上游原始 manifest。该目录是 **IMF 整句、2 步、完整 Vocos 合成**，不经过 TTS 流式音频拼接；默认流式入口的 10 步设置不适用于这里。

发现以下输入本身就带有重复的例子：

| 文件 | 实际输入片段 | IMF 155k ASR | FM 155k ASR |
| --- | --- | --- | --- |
| 0064.wav | 导航导航开始 | 导航，导航开始 | 导航，导航开始 |
| 0114.wav | 要保持独立思独立思独立思考 | 要保持独立思、独立思、独立思考 | 要保持独立思、独立思、独立思考 |
| 0131.wav | 女性可女性可以成为 | 女性和女性可以成为 | 女性可，女性可以成为 |

这些重复已存在于上游 `tts_text` 和 `ref_text`，0064、0114 的音素也明确重复，不能把这几个样例归为 IMF 凭空新增的重复。0064、0114 在两模型的 CER 都为 0：**忠实复读输入中的口吃，同样可以获得零错误率。** 另外，0135 的输入含“为为”，0147 含“一一百”，两模型转写都只保留一个字；没有重复的转写也不能替代对短音节重复的听测。

这 200 条输入只有 **115 条不同文本**；29 组文本出现多次，共 85 条额外重复记录。例如“自动驾驶将大幅提升出行安全，效率。”出现 8 次，位于 0003、0007、0013、0022、0036、0057、0140、0197。因此连续播放不同文件也会反复听到同一句。200 个 WAV 均可正常读取，都是 24 kHz 单声道，未发现整个文件解码后逐样本完全相同的副本。

本次确认的是输入重复及其在既有转写中的体现，尚未完成人工逐条听测，不能据此排除其他文件中的模型额外重复。原始评测集和历史分数保持原样；若评估自然朗读稳定性，需要另建去重、校正文案后的固定测试集，并单独记录重复失败样例。

核查来源：[IMF 155k 逐句记录](/119010446/tts-assets/training_runs/ljs_majestic_100h_imf_h1_b48_from21k_500ep_20260915/eval/step_00155000/details.jsonl)、[FM 155k 逐句记录](/119010446/tts-assets/training_runs/ljs_majestic_100h_backbone21k_20260914/eval/step_00155000/details.jsonl)、[上游中文文本](/119010446/tts-assets/chenmingjie/lits-tts/output/teacher_student_step2_seedtts200_20260715/teacher/schedule_uniform/zh/seedtts_zh_manifest.jsonl)。
